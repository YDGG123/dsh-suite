## 内容说明

| 文件 | 内容 |
|---|---|
| 01-home | 工作区、连接状态、运行中会话、最近会话列表、搜索 |
| 02-bots | Bot 团队页：4 个 Bot + 群聊，含「正在干活：第 3 步」实时状态 |
| 03-plugins | 插件列表：官方 2 个 + 已安装 4 个，带开关状态 |
| 04-presets | Agent 预设选择（6 个预设，含当前选中） |
| 05-tasks | 定时任务列表（每天 / 每周 / 一次） |
| 06-settings | 设置页：主题、语言、字体、预设、模型、权限、网关地址、版本 |
| 07-session | 会话对话页：用户提问 → 工具调用 → 参数 → 输出 → Bot 总结 |

## 生成方式

截图由模拟器 + 演示数据注入生成，不是真机实时抓取。要重新生成：

1. 检查出对应版本的 App 源码
2. 应用演示数据补丁（注入示例会话、团队、插件、任务与对话）
3. 模拟器安装 Debug 构建，逐屏启动截图
4. 用 `simctl status_bar` 覆盖状态栏时间为 9:41

**注意**：Bot 页的头像由桌面端 ds-bot 提供（矢量形象），不在 App 资源包里；截图中的头像是按同一渲染路径注入的演示数据。
